# P2-V0.13.5 — Mobile Work Specification Review

Status: IMPLEMENTATION CANDIDATE
Date: 2026-08-22

## Objective

Keep Work Specification review usable on phone-sized viewports without allowing the governed surface to consume the conversation workspace or be obscured by the persistent composer.

## Problem

On a 390×844-class mobile viewport, an expanded Work Specification can grow beyond the visible workspace. The fixed composer then visually overlaps specification content, making contract review feel broken even though the underlying content remains present.

## Requirements

1. Expanded Work Specification content on compact viewports must be height-bounded and internally scrollable.
2. The specification summary, approval/refresh controls, and disclosure control remain visible while reviewing the contract.
3. Expanded specification material must not intersect the composer region on supported phone viewports.
4. Phone interaction targets remain at least 44 pt.
5. Desktop and tablet Work Specification behavior remains unchanged unless required for parity.
6. Approval continues to be explicit and server-authoritative; this release changes presentation only.
7. Conversation, Code execution, amendment recovery, authentication, and autonomy authority are unchanged.

## Acceptance criteria

- On the 390×844 browser acceptance viewport, a captured draft can be expanded and reviewed without the Work Specification surface overlapping the composer.
- Long acceptance/constraint content remains reachable through scrolling inside the expanded specification body.
- The mobile Work Specification controls remain non-overlapping and usable.
- Existing client typecheck, export, browser/Skia acceptance, API regression, protected promotion evaluation, and DSPy release gates continue to pass.

## Non-goals

- Redesigning the Work Specification visual language.
- Changing specification generation or approval semantics.
- Changing the active product specification identity shown in existing conversations.
- Changing engineering-run or bounded-autonomy authority.
