# Parallax 2.0 v0.13.0 — Identity & Workspace Polish

Status: APPROVED FOR IMPLEMENTATION
Spec ID: P2-V0.13.0
Depends on: P2-V0.12.0
Method: operator visual review + identity refresh + interaction correction + exact-head release verification

## 1. Objective

Raise Parallax from a functional visual prototype to a coherent premium workspace by replacing the current optical mark with the operator-approved 3D knot identity, making ambient motion visibly calm rather than effectively static, integrating Work Specification styling with the conversation material, fixing response-follow behavior, synchronizing the optical inscription effect to streamed text, and improving the left navigation rail and top workspace banner.

## 2. User outcome

Parallax should feel alive and authored without becoming busy. The new knot mark is recognizable at both brand and chat-avatar scale. The background drifts visibly over several seconds. A response begins in view automatically and remains clear of the composer. The laser/etching effect visibly tracks the arriving text instead of independently retyping it. Navigation, top chrome, Work Specification, conversation material, and identity all belong to one visual system.

## 3. Scope

- Replace the existing aperture/circle Parallax mark with the approved transparent-background 3D interlocking-knot artwork.
- Preserve the approved violet/indigo/cyan 3D shading and glossy depth of the mark.
- Use the same mark for sidebar branding, mobile header identity, assistant chat avatar, thinking state, auth surfaces, and empty state.
- Animate the mark with a slow continuous 360-degree spin when reduced motion is not enabled.
- Add a restrained moving theme-colored highlight/sweep over the mark on web so the gradient appears to travel around the form; the effect must remain subordinate to the mark's original 3D shading.
- Keep the logo free of any circular background plate or enclosing badge.
- Increase `LivingSurface` time scale so broad chroma movement is perceptible over a normal 5–15 second observation while remaining calm and low-frequency.
- Restyle Work Specification as rounded translucent optical material rather than a peach-edged editorial panel.
- Keep specification status, revision, objective, explicit approval, expansion, and durable semantics unchanged.
- Add conversation-thread follow behavior so the newest assistant response enters the viewport automatically when responding starts.
- Keep active response content above the composer with dynamic bottom clearance.
- Stop automatic follow when the operator intentionally scrolls materially away from the live edge; resume follow for a new response.
- Rework the laser/optical typesetter so streamed text is rendered immediately and the optical head follows the newest rendered glyph rather than running a separate independent character clock.
- Replace the long scanner-like beam with a compact premium engraving head: short violet/indigo trail, bright lavender core, cyan hot point, and brief themed fresh-glyph energy.
- Improve desktop left navigation and top banner material, hierarchy, active conversation treatment, spacing, and brand presence without adding unnecessary controls.
- Preserve mobile geometry fixes from v0.11.1 and conversation-material behavior from v0.11.0.

## 4. Security and authority

This is a client presentation and interaction release. It does not expand Parallax execution authority and does not change API, authentication, authorization, persistence, Work Specification semantics, Reason semantics, Code semantics, Engineering Runs, or server-owned acceptance authority.

- Google/Supabase remains the identity provider boundary.
- Parallax server-owned authorization remains authoritative.
- Root bearer remains server-side break-glass / explicit automation compatibility only.
- No provider token, secret, credential, hidden reasoning, or privileged execution state is exposed by the new UI.
- The embedded logo asset contains only public visual data.

## 5. Identity contract

The production mark must satisfy all of the following:

- recognizable interlocking three-loop knot silhouette matching the operator-approved artwork;
- transparent outside the knot with no circular plate/background;
- glossy dimensional shading retained at normal sidebar/header sizes;
- theme palette dominated by deep blue, indigo, violet, magenta highlights, and cyan energy;
- slow 360-degree spin that never reads as a loading spinner;
- moving highlight/sweep is restrained and does not flatten or recolor the entire mark;
- same visual mark is used for brand and assistant avatar rather than maintaining separate logo/emoji identities;
- reduced motion presents a stable static mark.

## 6. Conversation-follow contract

- Starting a new assistant response automatically brings the response start into the visible thread region.
- While the operator remains at the live edge, streamed growth remains visible above the composer.
- The composer height is measured and used to provide real content clearance instead of relying on a brittle fixed padding value.
- If the operator scrolls materially upward during a long response, Parallax stops forcing the thread to the live edge.
- A new operator message re-enables live-edge following for the next response.
- No message content is covered by the composer at the live edge on validated mobile or desktop viewports.

## 7. Optical inscription contract

- streamed text is rendered as soon as it is received from SSE;
- no second client-side typing timeline is allowed to lag or race ahead of the stream;
- the engraving head targets the end of the newest rendered text line;
- the visual head is compact and localized, not a 100+ px scanner beam;
- the newest short glyph tail carries violet/lavender etched energy and cools quickly into normal selectable text;
- active head movement may ease between measured positions but must not invent text timing;
- completed response text remains ordinary selectable narrative text;
- reduced motion shows streamed text normally without animated head motion.

## 8. Ambient motion contract

- the v0.12 broad diffused chroma composition remains the basis;
- drift must be perceptible during a 5–15 second observation rather than requiring minutes to notice;
- movement remains continuous, low-frequency, non-bouncing, non-particle, and subordinate to text;
- activity may increase chroma intensity modestly but must not materially accelerate the background;
- reduced motion freezes time-dependent motion.

## 9. Navigation and governed-surface contract

- desktop rail uses richer translucent optical material, clearer active-conversation depth, and stronger brand hierarchy without becoming a dashboard sidebar;
- top banner uses deeper optical material and subtle themed depth while remaining compact;
- mode controls remain explicit and accessible;
- Work Specification uses rounded translucent material consistent with conversation surfaces and no heavy solid left rule;
- status and approval remain explicit through text, not color alone;
- mobile account/mode/Work Specification geometry from v0.11.1 remains non-overlapping.

## 10. Acceptance criteria

### AC-01 Approved knot identity
The old aperture/circle logo is removed from normal product surfaces and the approved transparent 3D knot mark is used consistently for brand and assistant avatar identity.

### AC-02 Logo motion
Automated/browser evidence shows the mark changes over time when motion is enabled and reduced-motion provides a stable static mark. Web implementation includes a restrained traveling theme highlight without a circular background plate.

### AC-03 Perceptible calm background
Browser evidence confirms visible frame change over a short observation window while implementation remains a single low-frequency Skia runtime effect with protected center contrast.

### AC-04 Integrated Work Specification
Work Specification retains durable semantics and operator approval while using rounded translucent optical material without the prior heavy peach left rule.

### AC-05 Response auto-follow
A newly started assistant response is automatically brought into view and its live edge is not hidden behind the composer on desktop or 390x844 mobile validation.

### AC-06 Respect operator scroll intent
Automatic live-edge following stops when the operator scrolls materially away from the bottom during a response and re-enables for a subsequent new response.

### AC-07 Stream-synchronized etching
The optical typesetter displays actual streamed text immediately, the head follows the newest rendered glyph, and no independent artificial character clock controls text visibility.

### AC-08 Premium engraving head
The active optical head is compact, themed, and localized; browser evidence shows fresh-glyph energy while responding and ordinary selectable text after completion.

### AC-09 Navigation/header polish
Desktop visual evidence shows enhanced left rail and top banner hierarchy without horizontal overflow, control collision, or loss of conversation focus.

### AC-10 Regression protection
Google authentication/authorization, Reason, Code, SSE, durable conversations, Work Specifications, approved-spec execution binding, Engineering Runs, mobile viewport geometry, reduced graphics, reduced motion, and protected evaluation continue to pass.

### AC-11 Release verification
Specification validation, API tests, client typecheck/state tests, web export, browser/Skia acceptance, Google-auth acceptance, Code-binding acceptance, protected evaluation, DSPy release compilation, Vercel READY state, health/readiness, protected-route checks, and runtime-error checks pass before v0.13.0 is recorded as deployment-verified.

## 11. Non-goals

- Adding new model/tool authority.
- Changing server APIs or database schema.
- Replacing Google authentication.
- Adding decorative particles, fast logo spinning, video backgrounds, sound, or a circular badge around the new knot.
- Turning Work Specification or navigation into dashboard-style card collections.

## 12. Risks and mitigations

- **Logo asset adds bundle weight:** embed a compact optimized transparent WebP sized for UI use rather than the full source render.
- **Logo motion resembles loading:** use a long rotation period and disable under reduced motion.
- **Highlight sweep looks synthetic:** keep opacity low and preserve the baked 3D shading as the dominant image.
- **Autoscroll fights reading:** track distance from live edge and respect deliberate user scroll-away.
- **Laser still drifts from text:** derive head position from actual received text and measured layout only.
- **Background becomes distracting:** increase temporal perceptibility rather than brightness or high-frequency detail.
- **Chrome competes with content:** improve material and hierarchy while keeping dimensions compact.
