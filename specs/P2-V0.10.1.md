# Parallax 2.0 v0.10.1 — Ambient Laser Conversation Refinement

Status: APPROVED FOR IMPLEMENTATION
Spec ID: P2-V0.10.1
Depends on: P2-V0.10.0
Method: conversation-surface refinement + ambient Skia motion + optical text inscription tuning

## 1. Objective

Refine the conversation experience so messages feel lighter, quieter, and more premium while restoring a clearly visible purple laser-etching effect for active assistant responses and introducing a calm animated lava-lamp-like ambient background.

## 2. Scope

- Replace conventional solid-line conversation boxes with softly rounded translucent neutral-gray glass surfaces.
- Remove persistent hard outlines from normal user and assistant conversation bubbles.
- Keep subtle separation through translucency, shadow/contrast, spacing, and optional low-opacity edge light rather than full box strokes.
- Preserve right-aligned user messages and left-aligned assistant responses as one coherent visual family.
- Restore a clearly visible themed optical inscription effect during active assistant responses.
- Make the optical head, beam, fresh-glyph glow, and cooling trail violet/purple-led, with only restrained cyan used as a secondary optical highlight.
- Evolve the existing Skia LivingSurface into a calm lava-lamp-like ambient field with large organic indigo/violet forms that drift and deform slowly behind the conversation.
- Keep the ambient field low-frequency and low-contrast so text remains dominant.
- Preserve reduced-motion and reduced-graphics semantics.
- Refine mobile widths, radii, padding, and vertical rhythm around the conversation.

## 3. Non-goals

- No authentication, Google OAuth, allowlist, role, session, API, database, Work Specification, Engineering Run, or execution-authority changes.
- No particle field, starfield, scanner HUD, or high-frequency decorative animation.
- No conventional bright neon chat bubbles.
- No external image assets or copied brand artwork.
- No typography dependency or font-licensing change.

## 4. Security

- Google/Supabase identity, Parallax authorization, owner/member policy, signed HttpOnly session cookies, bearer compatibility, and same-origin `/p2-api` routing are unchanged.
- The client continues to receive no provider secret, Google client secret, production root access secret, or database credential.
- The visual layer cannot redefine authentication state, authorization, Work Specification approval, required acceptance criteria, protected evaluation, execution policy, or deployment authority.
- The laser and ambient effects are decorative state consumers only; they do not become security or trust signals.
- Reduced-graphics fallback remains semantically equivalent and must not bypass any protected route or authorization gate.

## 5. Conversation visual rules

### User message

- Right aligned.
- Rounded glass surface, approximately 18–22 px corner radius.
- Neutral graphite/gray translucency with a slight indigo bias.
- No persistent solid outline.
- Maximum width remains narrower than the assistant response on desktop and compact on mobile.
- Optional tiny `YOU` metadata may remain, but should not dominate.

### Assistant message

- Left aligned.
- Rounded glass surface using the same material family as the user message.
- Slightly broader than the user bubble but not a full-width panel.
- No persistent full rectangular border, left rail, or horizontal rule.
- Assistant identity remains outside/above the bubble as a compact signature.
- Active optical inscription occurs inside this surface.

### Composer

- Rounded translucent neutral-gray glass.
- Border reduced to a very low-opacity edge or removed where contrast is sufficient.
- Send control retains violet identity.

## 6. Purple laser inscription

The active assistant response must visibly read as text being optically etched into the interface.

Required behavior:

- inscription progresses left-to-right with the streamed response;
- a violet optical head tracks the current inscription position;
- the active head includes a concentrated purple-white core, violet glow, and short soft beam/trail;
- freshly inscribed glyphs appear brighter lavender/violet with a restrained glow;
- glyphs cool back to standard Parallax narrative text after the head passes;
- the effect follows the actual growing text target and does not replay the entire answer after streaming completes;
- completed text remains selectable standard text;
- reduced-motion mode immediately renders stable final text and suppresses moving beam/head effects.

The effect should feel like a fine purple laser etching glass, not like a typewriter cursor or a cyan scanner.

## 7. Ambient lava field

The background is a full-screen Skia layer behind product content.

Required behavior:

- use 3–5 very large organic forms/fields rather than small particles;
- dominant hues are deep indigo, violet, midnight blue, and restrained lavender;
- forms drift and deform slowly with non-synchronous periods so looping is not obvious;
- typical motion cycle should feel on the order of 20–45 seconds, not seconds;
- background intensity may lift slightly while Parallax is actively responding, but should remain calm;
- central reading area retains a dark contrast bias;
- no bright blob may sit beneath text at enough intensity to reduce readability;
- reduced-motion freezes the field into a stable composition while preserving depth.

## 8. Accessibility

- Final assistant text remains selectable.
- Core text contrast remains at the established production standard.
- Motion is decorative and never communicates required state alone.
- Reduced-motion suppresses moving laser and background drift.
- Interaction targets remain at least 44 pt where applicable.
- Message role remains identifiable by alignment/metadata, not color alone.

## 9. Acceptance criteria

### AC-01 Conversation bubbles are visually lighter
User and assistant messages use softly rounded translucent gray/graphite glass with no persistent hard full-box outline.

### AC-02 Message family is coherent
User and assistant bubbles share material/radius language while remaining distinguishable through alignment, width, metadata, and subtle tint.

### AC-03 Purple laser is clearly visible
During an active assistant response, the optical head, beam/trail, and fresh-glyph state are visibly purple/violet and unmistakably read as optical etching rather than ordinary text reveal.

### AC-04 Laser remains streaming-native
The inscription tracks growing streamed text and completed text remains selectable; the response is not replayed after server completion.

### AC-05 Calm animated lava field is present
The Skia background visibly contains slow, large organic indigo/violet forms with non-obvious looping and no particle/HUD character.

### AC-06 Reading contrast remains dominant
Ambient forms and laser glow do not reduce narrative readability or overwhelm the conversation.

### AC-07 Mobile composition improves
On phone-sized widths, bubble widths, radii, padding, spacing, and composer proportions avoid the boxed/full-width panel feeling shown in the prior production screenshot.

### AC-08 Reduced-motion parity
Reduced-motion freezes ambient motion, removes moving laser/head behavior, and preserves all content/capability.

### AC-09 Existing product contracts are unchanged
Google identity, authorization, Reason, Work Specifications, Code bindings, persistence, and execution boundaries remain behaviorally unchanged.

### AC-10 Release verification passes
Specification validation, API tests, client typecheck, response-state tests, web export, browser/Skia visual acceptance, protected Engineering/Reason/Code evaluation, DSPy release compilation, Vercel readiness, production health/readiness, and runtime-error checks pass before deployment verification is recorded.

## 10. Implementation constraints

- Prefer targeted changes to `LivingSurface`, `LaserTypesetter`, `App` conversation styles, theme tokens, visual acceptance, and release metadata.
- Do not add a new animation framework.
- Do not add a database migration.
- Do not change API contracts.
- Keep the ambient field GPU-friendly and shader-based where Skia is available.
- Preserve the existing static fallback path.

## 11. Release gate

Production promotion requires an exact-head successful full CI run, READY relevant preview deployment, successful production Vercel promotion, HTTP 200 from production root and same-origin health/readiness, expected protected authentication behavior, no material runtime-error cluster, and authoritative record updates. `DESIGN-SYSTEM.md` must record the durable conversation-material, ambient-lava, and purple optical-inscription rules once validated.
